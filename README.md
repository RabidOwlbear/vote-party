# vote-party

Vote party is a lightweight voting application for Foundry VTT.

Use:

Once activated the module will add a control button to the left of the active players panel in the lower left section of the screen.

Clicking the "New Vote" button will open the vote config app where the vote caller can nae the vote and add voting options. If the vote caller wishes to participate in the vote simply click the "Caller gets vote" box in the lower left corner of the config app.

When the vote is configured click the "Call Vote" button to open the voting app for all active users.

The Voting application lists the name and description of the current vote, and all the vote options. Once the user has selected their choice by clicking the box to the right of their choice, clicking the 'Vote!" button will open the results panel.

The results panel displays the vote name and oprions, and updates each option with a visual count as each user votes. Once the vote is complete and all votes are in the winning option, or options in case of a tie will flash green.

For the vote caller, once the vote is complete a "Re-call" Vote button will appear allowing for the same vote to be called again.

At this time only the gm has ability to call votes.
